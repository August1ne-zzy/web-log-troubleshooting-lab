# ログと指標の定義

## 記録の単位

1 行は、応答本文を書き込み・flush できた GET リクエスト 1 件です。全行に `environment=local-lab`、`traffic_type=synthetic` を付けます。

| フィールド | 定義 |
| --- | --- |
| `timestamp` | GET ハンドラー開始時刻。サーバーは UTC で記録。取り込み時は UTC・小数 6 桁に統一 |
| `request_id` | リクエストごとの UUID。正規化して SQLite の主キーに使用 |
| `method` | 現在の取り込み対象は GET |
| `path` | クエリ文字列を除いたパス。IP、Cookie、要求ヘッダーは保存しない |
| `status` | HTTP ステータスの整数。取り込み時に 100～599 を許可。現在のサービスは 200/404/500 を生成 |
| `duration_ms` | ハンドラー開始から応答本文の書き込み・flush 完了まで。単調増加時計によるミリ秒 |

計測時間にはログの書き込み時間を含みません。クライアントの受信完了や接続待ち時間そのものを測定する値ではありません。生成器の `client_ms` は接続・受信を含む別の計測で、JSONL には保存しません。

## 集計対象と式

対象は指定 DB に保存されている一意なリクエスト全件です。全パス・全ステータスを含みます。特定時間帯のフィルターは未実装です。表示する開始・終了時刻は対象データの最小・最大リクエスト開始時刻であり、観測時間の長さや稼働率を示しません。

| 指標 | 定義 |
| --- | --- |
| リクエスト数 N | 受理後・重複排除後の行数 |
| 4xx 率 | 400～499 の件数 / N × 100 |
| 5xx 率 | 500～599 の件数 / N × 100 |
| 総エラー率 | 400～599 の件数 / N × 100 |
| 平均応答時間 | 全 N 件の `duration_ms` の算術平均 |
| 最大応答時間 | 全 N 件の `duration_ms` の最大値 |
| 遅いリクエスト数 | `duration_ms >= slow_ms` の件数。既定値は 500 ms |
| 遅いリクエスト率 | 遅い件数 / N × 100 |

パス別集計では、そのパスの件数が分母になります。応答時間は失敗応答も含みます。比率と応答時間の出力は小数 3 桁に丸めます。N=0 のとき件数は 0、比率・平均・最大・開始終了時刻は JSON の null（Markdown では N/A）です。

4xx をサーバー内部故障と同一視せず、4xx と 5xx を分けて表示します。500 ms はこの教材の固定待機に合わせた実験用閾値であり、実サービスの SLO ではありません。p95、稼働率、スループットは現段階では算出していません。

## 入力検証と重複排除

JSON オブジェクト、必須フィールド、UUID、タイムゾーン付き ISO 時刻、固定の実験ラベル、GET、パス、ステータス範囲、有限で非負の応答時間を検証します。bool は Python で整数の一種ですが、ステータスや時間としては受理しません。非標準の NaN/Infinity、重複 JSON キーも拒否します。未知の追加フィールドは保存しません。

- 同一 ID・正規化後の保存フィールドが同一：重複として数え、追加しない。
- 同一 ID・保存フィールドが異なる：競合として拒否。元の行を上書きしない。
- 新規 ID：内容が似ていても別のリクエストとして追加。
- 不正な行：行番号・理由を報告し、集計対象から除外。空行は別カウントで無視。

DB 処理中の予期しないエラーは、その取り込み処理の追加行をロールバックします。不正入力行の検出は続行し、正常行をコミットする仕様です。取込結果の `rejected` と終了コードを必ず確認します。

## 検証範囲

一意性、分母、500 ms 境界、時差の正規化、空データを固定データで検証し、実際の HTTP リクエストからの取り込みも確認します。負荷試験、長期保存、他 OS での実行、巨大ファイルへの耐性は未検証です。
